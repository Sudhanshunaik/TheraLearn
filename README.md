# TheraLearn Ecosystem

Welcome to the **TheraLearn Ecosystem** repository (originally developed for the RIT Webathon)! This workspace contains a collection of projects focused on cognitive development, therapeutic learning, and interactive gameplay for children with Down syndrome.

---

## 📁 Repository Structure

This repository is organized into the following main projects:

### 1. [TheraLearn](./TheraLearn-main/TheraLearn-main/)
**An Educational Platform with Therapeutic Games for Children with Down Syndrome**

TheraLearn is a comprehensive web application designed to support the cognitive development and learning of children with Down syndrome through interactive games, therapy activities, and educational content. It combines modern web technologies with evidence-based therapeutic approaches to create an engaging and supportive learning environment.

* **Tech Stack:** Node.js Backend, React/Web Frontend.
* **Running Locally:**
  Navigate to the project directory and run:
  ```bash
  cd TheraLearn-main/TheraLearn-main
  npm install
  npm start
  ```
  *(This concurrently starts both the frontend and backend servers).*

### 2. [React Memory Game](./react-memory-game-main/react-memory-game-main/)
**An Interactive Memory Challenge**

A responsive and engaging memory game designed to test and improve memory by challenging users to match pairs of cards with identical images. The game offers a seamless experience across desktop, tablet, and mobile devices.

* **Features:** Multiple difficulty levels (5 levels), customizable themes, best-score leaderboard.
* **Tech Stack:** React, Vite, TailwindCSS.
* **Running Locally:**
  ```bash
  cd react-memory-game-main/react-memory-game-main
  npm install
  npm run dev
  ```

### 3. [Webathon Template](./webathon-template/)
**Next.js Starter Boilerplate**

A clean Next.js project bootstrapped with `create-next-app`, intended to be used as a quick-start template for building new features or applications during the webathon.

* **Tech Stack:** Next.js (App Router), React, TailwindCSS.
* **Running Locally:**
  ```bash
  cd webathon-template
  npm install
  npm run dev
  ```

## 🚀 Getting Started

To explore the projects in this workspace:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sudhanshunaik/RIT-webathon.git
   cd RIT-webathon
   ```
2. **Navigate into the specific project folder** you want to run (e.g., `TheraLearn-main/TheraLearn-main`).
3. **Install dependencies** using `npm install`.
4. **Start the development server** as instructed in the respective project's README.
